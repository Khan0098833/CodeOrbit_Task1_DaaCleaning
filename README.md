# CodeOrbit_Task1_DaaCleaning
CodeOrbit Task 1 – Data Cleaning

Objective

To clean and preprocess a retail store sales dataset using Python and Pandas.

Dataset

The dataset used for this task is Retail Store Sales. It contains transaction details such as Transaction ID, Customer ID, Category, Item, Price Per Unit, Quantity, Total Spent, Payment Method, Location, Transaction Date, and Discount Applied.

Data Cleaning Performed

- Loaded the dataset using Pandas.
- Checked the dataset structure and data types.
- Identified missing values.
- Checked for duplicate records.
- Handled missing values in the required columns.
- Checked and converted relevant data types.
- Saved the cleaned dataset as "retail_store_sales_cleaned.csv".

Files

- "Task1_DataCleaning.ipynb" – Jupyter Notebook containing the complete analysis and cleaning process.
- "retail_store_sales.csv" – Original dataset.
- "retail_store_sales_cleaned.csv" – Cleaned dataset.

Tools Used

- Python
- Pandas
- Jupyter Notebook

Outcome

The dataset was cleaned and prepared for further data analysis.
